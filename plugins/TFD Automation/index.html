TFD Automation

TFD Automation Guide

How It Works

  • • Items go straight to your inventory (you won't see them appear)
  • • Start in your den for best results
  • • Choose how long to wait before collecting rewards
  • • Automatically recycles items you don't want

Best Practices

  • • Stay in your den while it runs
  • • Don't switch rooms during automation
  • • Check your inventory when done to see your items
  • • Use loop mode to run multiple times

Efficient Mode (🚀)

  • • Detects items before the chest opens by analyzing quest packets
  • • Only collects valuable items (whitelisted) and skips unwanted ones
  • • Uses optimized crystal packets generated from detected patterns
  • • Skips reward collection entirely if no valuable items are found
  • • Uses faster crystal delays (10ms default) instead of randomized delays

Special Mode (8x speed):

  • • Collects additional layer 3 & 4 crystals during the wait period
  • • Utilizes wait time(to reach 11:00-13:00) for extra crystal collection, making runs faster
  • • Only works when Efficient Mode is enabled

Item Filtering System

  • • Add item IDs you want to keep
  • • Items you don't want get recycled automatically
  • • You'll hear a sound when good items are found
  • • Use the "Find IDs" buttons to see what items are available

Important Notes

  • • Wait time is calculated automatically
  • • Failed runs will retry automatically
  • • Your stats are saved between sessions
  • • Stops if you lose connection

Settings Overview

  • • Max Retries: How many times to retry if it fails
  • • Loop Mode: Run once or many times
  • • Sound alerts: Get notified when good items are found
  • • Efficient Mode: Makes crystal collection faster and smarter
