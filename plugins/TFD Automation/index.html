TFD Automation

TFD Automation Guide

Prerequisites

  • You MUST be in your den before starting automation
  • Do NOT open your inventory or check items in-game during a run. Use the Item Log in this plugin instead
  • For long or looped runs, enable Performance Mode or Headless Mode via F10 Mod Menu. Flash will slow down, this just extends the session

Modes

Normal: Sends all crystal packets, waits the selected time, collects all 4 prizes, recycles non-whitelisted items
Efficient: Detects crystal variant from server data and sends only matching packets (140 vs 279). Detects prize contents before collection. Only collects green/yellow crystals instantly, saves blue/white for the wait period
Special (requires Efficient): Only collects green/yellow crystals instantly. If it doesn't have a whitelisted item it leaves. Fastest mode

Item Filtering

  • Whitelisted items are KEPT. In normal mode everything else is RECYCLED automatically
  • Default whitelists include commonly valuable items. Search by name to add more

Troubleshooting

  • Game crashes on long runs are normal (Flash limitation). Just restart the game and re-run
  • If automation stalls, stop it and restart from your den

Do NOT flood #sj-help on Discord with usage questions. Read this guide first.
